# Error Handling Framework

## ClassifyError.groovy

Provides:

- Error classification
- Root cause extraction
- Technical error classification
- Functional error classification
- Business error classification
- Retry eligibility determination
- MPL enrichment
- Cloud ALM enrichment
- Data Store metadata generation

## SetBusinessError.groovy

Provides:

- Standardized business error creation
- Business validation support
- Integration with ClassifyError framework
